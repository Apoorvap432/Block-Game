# Breakout Arena

A simple browser-based Breakout game built with HTML, CSS, and JavaScript.

## Overview

Breakout Arena is a classic arcade-style game where the player moves a paddle left and right to bounce a ball and break all the blocks on the screen. The game tracks the score and ends when all blocks are cleared.

## Features

- Classic Breakout gameplay
- Keyboard controls with left and right arrow keys
- Score tracking
- Win state when all blocks are destroyed
- Responsive layout for smaller screens
- Lightweight front-end implementation with no build step

## Tech Stack

- HTML
- CSS
- JavaScript
